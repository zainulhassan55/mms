# MMS Workflow Guide

Plain-language illustrated guide to how the Manuscript Management System works.

## Files

| File | Description |
|------|-------------|
| `MMS-Workflow-Guide.pdf` | Printable PDF (open this) |
| `MMS-Workflow-Guide.html` | Same content in HTML |
| `figures/` | Screenshots and UI figures |
| `make-pdf.mjs` | Rebuild the PDF from the HTML |

## Rebuild the PDF

```powershell
cd D:\Hassan\Websites\mms\docs\workflow-guide
npm install
node make-pdf.mjs
```

Or open `MMS-Workflow-Guide.html` in Chrome/Edge and use **Print → Save as PDF**.
